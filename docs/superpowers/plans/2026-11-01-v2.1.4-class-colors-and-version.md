# Implementation Plan: SwedgeTimer v2.1.4 — Raid Class Colors, Shaman Blue on Era, HUD Isolation & Single Power Bar Verification

## Overview

This plan implements the requirements for SwedgeTimer v2.1.4:

1. Confirm HUD isolation: Ensure SwedgeTimer's HUD shows its own cooldown numbers on its FontString while completely suppressing external addons (OmniCC, ElvUI, Tukui, Blizzard action bar countdowns) from hijacking or mutating its cooldown frames.
2. Raid Class Color API: Implement normalized class color resolution in `compat.lua` (`st.api.get_class_color` and `st.api.get_class_color_table`).
3. Shaman Blue on Classic Era: On Classic Era (where Blizzard left `RAID_CLASS_COLORS["SHAMAN"]` as pink/paladin), enforce canonical Shaman blue (`{ 0.0, 0.44, 0.87 }` / `{ 0, 112, 222 }`) for both the base swing bar and the shaman weave spark.
4. Bar color procs preserved: Ensure class color changes for abilities (Warrior HS/Cleave, Druid forms/Maul, Paladin seals, Hunter Raptor Strike) continue to trigger when active.
5. Power bar single-bar verification: Ensure Druid and Rogue use only 1 power bar.
6. Bump version to 2.1.4 across all 7 TOCs, `main.lua`, `CHANGELOG.md`, and docs.

## Tasks

### Task 1: Cross-Client Class Color API in `compat.lua`

- Add `api.get_class_color(class_filename)`:
  - If `class_filename` is missing, query `UnitClass("player")`.
  - Normalize to uppercase string.
  - If `class == "SHAMAN"` and `st.family == "ERA"`: return `0.0, 0.44, 0.87`.
  - Read `RAID_CLASS_COLORS` global table (or `C_ClassColor.GetClassColor`).
  - If `class == "SHAMAN"` and `c.r > 0.9 and c.b > 0.7`: return `0.0, 0.44, 0.87`.
  - If valid `c.r, c.g, c.b` found: return `c.r, c.g, c.b`.
  - Fall back to `CANONICAL_CLASS_COLORS` table (0-1 floats).
- Add `api.get_class_color_table(class_filename, alpha)`:
  - Convert `(r, g, b)` to 0-255 integers + alpha `[0-1]` (default 0.9).
  - Return `{ math.floor(r * 255 + 0.5), math.floor(g * 255 + 0.5), math.floor(b * 255 + 0.5), a }`.
